使用说明
打开网站后自动读取同目录 configs 中的云端配置；网站需保留同目录下的 vendor 文件夹。上传的数据在浏览器内处理。点击“上传数据”或将文件拖入页面，支持 Excel、CSV、JSON、TXT、PMSD。CSV/TXT 使用制表符、逗号或分号分列，第一行填写列名。
数据 JSON 支持对象数组（每条记录包含时间和各序列）、带首行列名的二维数组，或 {"columns":[列名],"data":[数据行]}。TXT 按表格文本读取。Excel 表格可通过“粘贴数据”标签载入。
Excel 支持 .xlsx、.xls、.xlsm、.xlsb、.xltx、.xltm、.xlt、.xlw 以及 Excel 2003 XML（.xml）。可切换工作表，保持原始行顺序；日期数值可按单元格格式自动识别，公式读取文件中保存的计算结果。含宏文件仅提取表格数据，不执行宏。加密文件请先另存为不带打开密码的副本。
PMSD 可直接导入已支持的 PMSAMPLE v2 采样结构，自动读取字段名称、单位和数值，并识别可选 END1 文件结束块；无效采样保留断点，损坏或不支持的文件会提示并保留原图。建议保留原始文件名，以便结合文件头推断原时区；无法识别时按浏览器本地时区显示并提示。时间显示至毫秒，多个分片不自动合并。
标题默认规则由 configs/regex.json 的 defaults.headerRule 定义，上传和粘贴均适用。可在“标题正则”中编辑；“恢复默认规则”使用当前已读取的 JSON 默认值。
第一行为名称，第一列为时间，其余列为数值。数值时间、Excel 日期、日期文本、时分秒均可识别；纯数值默认作为数值时间，Unix 时间戳请手动选择单位。日期按表格中的时间显示，带时区的 ISO 时间统一转为 UTC。数据保持原始行顺序，不按时间排序，曲线按原始行顺序连接。数值或日期横轴仍使用实际时间坐标；时间回退时曲线会向左连接。重复时间保留原行，悬浮时显示最近时间点中最先出现的一条记录。
每个序列按完整数据的最大最小值，匹配 configs/axes.json 中的默认坐标组；该文件同时定义各组默认区域比例及自动上下限的拓宽、取整规则。同组共用坐标轴，实际自动范围按已勾选曲线的数据计算。点击“曲线坐标”可逐条指定坐标组，点击“坐标范围”可设置手动上下限或恢复自动。手动范围可能隐藏超出部分，原始数据不变；时间横轴通过底部滑块或 Ctrl + 滚轮调整。
左侧“分类配置”分为坐标轴、标题正则、勾选序列三类，各自保存、导入、切换并记住最后选择。坐标轴配置保存时间格式、纵轴上下限、曲线分组及区域比例；勾选序列配置仅保存选择和颜色；标题正则配置仅保存标题处理规则。输入名称后点击保存，写入本地 IndexedDB，不会下载文件。同一分类同名会更新，不同分类可同名。本地列表可删除单项；云端列表只读，不提供删除。切换一类不会覆盖其他两类；旧版合并配置导入后自动拆为坐标轴与勾选序列两份。
“导出”将当前类型的 defaults 默认值和全部本地配置 configs 保存到一个 JSON 文档：axes.json、regex.json 或 selection.json。手动替换项目 configs 目录中对应文件后即可更新云端配置。导出不自动合并已有云端项，需保留时先导入到本地。选中云端项再保存会生成或更新本地副本，不会改写云端文件。
打开或刷新网页时自动读取相对路径 ./configs/ 下的 axes.json、regex.json、selection.json，无需选择文件夹。更新网站中的 JSON 后，点击“云端配置”标题右侧的“刷新”，即可重新读取。各分类分别记住最后选择与来源，原浏览器配置会一次性迁移到 IndexedDB。更换浏览器、打开地址或清理站点数据会影响本地配置，请用导出功能备份。
在“标题正则”中点击“编辑标题规则”，可修改正则、标志和替换表达式，用 $1、$2 引用捕获分组，并预览原始标题的处理结果。可停用或恢复默认规则。无匹配或替换后为空时保留原名；无效表达式不会应用。每次从原始列名处理，修改规则不会改变数据、当前勾选或坐标分配。点击应用后，再在标题正则分类中命名保存。
“坐标轴”分类中的“坐标区域”可设置每组起始、终止百分比（从顶部向下计 0～100%），支持小数、重叠与恢复默认。勾选序列配置按列名及同名出现次序匹配，新配置同时保存原始列名以便跨标题规则复用。上传或“导入到本地”可识别三类 JSON，自动归类；只导入不自动应用。数据文件不包含在配置内。
曲线区域随窗口大小自动铺满。点击工具栏左侧的侧栏按钮，可收起或展开序列与配置；分类配置默认折叠，点击标题展开。序列数值范围可将鼠标停留在名称上查看。
在曲线绘图区按 Ctrl + 鼠标左键开启虚线跟随，松开 Ctrl 后移动鼠标即可查看最近时间点；再次按 Ctrl + 左键固定当前位置。Ctrl + 鼠标右键显示或隐藏时间标签和数值框，保留虚线。鼠标移出绘图区后保留最后位置，重新进入后按当前跟随开关继续；普通右键仍打开浏览器菜单。新数据载入时清除旧标记。
加载数据时只勾选最后一次选择的勾选序列配置中能匹配的序列，未匹配的保持不选；没有选过配置时使用 configs/selection.json 中的 defaults.selectedSeries；交付默认值为空，不勾选任何曲线。可以先选配置再加载数据。点击“清空数据”清除当前曲线、粘贴内容和标记，保留三类配置列表及各自最后的选择。
数据不离开本机。单文件上限 50 MB，单表最多 250,000 行、512 列；较大数据建议减少同时显示的序列。
