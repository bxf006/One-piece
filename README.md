# 曲线查看

部署到静态网站后，打开或刷新网页即可自动读取相对路径 `./configs/` 中的云端配置。页面无需选择文件夹或运行启动命令。上传的数据在浏览器内处理，第三方 JS 独立保存在 `vendor/` 中。

## 获取与开始

将 `curve-viewer-static.zip` 解压后的内容上传到静态网站，保持 `index.html`、`vendor/`、`configs/` 在同一目录。`curve-viewer.zip` 则是包含源码、测试和维护工具的完整项目包。网站使用不需要 Node.js 或额外后台程序。

打开网站即可使用。页面自动读取 `./configs/axes.json`、`./configs/regex.json`、`./configs/selection.json`，点击“云端配置”标题右侧的“刷新”也会重新请求这三个文件。请求不使用浏览器缓存。云端配置可在没有上传数据时先行选择；数据区域初始为空，请上传自己的数据或粘贴表格。

默认值唯一保存在这三个 JSON 的 `defaults` 中，同类型的多套配置保存在 `configs` 数组中。网页初始化和“恢复默认”均读取 JSON，不将默认参数写入 HTML 或业务 JS。修改默认值后更新网站中的 JSON 并刷新网页即可，无需重新构建页面；最后选择的个人配置优先于默认值。

支持根目录和子目录部署。例如页面位于 `https://example.com/tools/curve/index.html`，配置位于 `https://example.com/tools/curve/configs/`。手动更新网站中的 JSON 后，刷新网页或点击配置刷新按钮即可读取新内容。

若地址栏以 `file://` 开头，说明是直接打开本地 HTML；浏览器会阻止自动读取相邻 JSON。请将静态包内容部署到网站后，通过 HTTP/HTTPS 网址访问。页面会明确提示这种打开方式限制，不再只显示 `Failed to fetch`。网站请求失败时会显示具体文件和请求地址，便于检查部署路径；HTTP 状态错误与配置内容错误分别提示。


## 使用

曲线区随窗口高度自动铺满，工具栏左侧的侧栏按钮可收起序列与配置，进一步扩大横向空间。侧栏中的分类配置默认折叠，点击标题展开；窄屏默认收起侧栏，展开时覆盖在图上。序列列表使用单行显示，鼠标停留在名称上可查看完整名称和数值范围。快捷键说明见右上角“使用说明”，跟随和标签状态保留在图表工具栏中。

1. 点击“上传数据”，支持 Excel（`.xlsx`、`.xls`、`.xlsm`、`.xlsb`、`.xltx`、`.xltm`、`.xlt`、`.xlw`、Excel 2003 `.xml`）及 `.csv`、`.json`、`.txt`、`.pmsd`，也可拖入文件，或使用“粘贴数据”。拖入多个数据文件时按顺序载入，最终显示最后一个成功载入的文件，不自动合并分片。
2. 第一行填写列名，第一列为时间，第二列起为数值序列。可切换工作表。
3. 加载时分别沿用三类配置中最后的选择；序列按最后选择的序列配置匹配，只勾选其中能匹配到的序列；未匹配的保持不选，没有选过配置时全部不选。仍可手动勾选或点击“全选”；搜索后“选中匹配 / 清空匹配”只影响搜索结果。
4. 默认关闭鼠标跟随。在曲线绘图区按 `Ctrl + 鼠标左键` 开启，松开 Ctrl 后移动鼠标，竖直虚线吸附最近时间点；再次按 `Ctrl + 左键` 停止跟随并固定最后位置。`Ctrl + 鼠标右键` 切换时间标签和数值框的显示，虚线保持。鼠标移出绘图区后保留最后位置的虚线与标签。数值框显示全部所选序列的该行数值（缺失值显示 `—`），右侧空间不足时移到左侧。
5. 拖动底部滑块缩放，或按 Ctrl 滚动鼠标；“重置视图”恢复完整时间范围。“曲线坐标”可为每条曲线指定坐标组；“坐标范围”或图上的范围标签可调整各纵轴的下限、上限，点击“应用”生效，支持负数和小数。
6. 展开“分类配置”，选择“坐标轴 / 标题正则 / 序列”中的一类。坐标轴分类可编辑坐标区域，标题正则分类可编辑标题规则。输入名称并点击“保存”，写入本地 IndexedDB；同类同名更新，不同名称新增，不同分类允许同名。保存不会下载文件。本地列表中的“×”可删除单项配置。
7. 每类分别显示“本地配置”和只读“云端配置”。“导入到本地”可多选 JSON；“导出”将本地当前类型的全部配置合并为一个 JSON 文件，可手动替换 `configs` 文件夹中对应文件。点击任一列表项即可应用，也可先选配置再加载数据；只导入不会自动应用。三类分别记住最后选择及来源，云端列表不提供删除按钮。
8. 点击“清空数据”移除当前数据、曲线、坐标设置、粘贴内容、预览和鼠标标记，保留三类已保存配置及各自最后选择；再次载入时重新匹配。读取文件期间清空按钮暂不可用。

本地配置与最后选择保存在当前浏览器、当前页面来源的 IndexedDB 中，数据文件本身不缓存。重新打开页面会读取数据库；返回页面时也会刷新其他同来源页面保存或删除的配置。更换浏览器、地址或打开方式，或清理浏览器站点数据后，本地列表可能不同，请用导出的 JSON 备份和迁移。

“云端配置”固定读取当前项目 `configs` 文件夹或部署后的同名静态目录，页面只读，不会自动上传或修改文件。网页启动即读取三个类型的 JSON，不提供选择文件夹入口。手动更新文件后，点击“云端配置”标题右侧的“刷新”，即可重新读取最新内容。

跟随与标签是两个独立开关，状态显示在图表工具栏；普通右键仍打开浏览器菜单。关闭跟随后，标签开关仍可使用。移出后重新进入绘图区，按当前跟随状态继续。缩放、窗口尺寸变化和纵轴范围调整时，标记仍对应原时间点；时间点缩放到视野外时暂时隐藏，回到可见范围后恢复。载入新数据、切换时间格式或修改标题规则会清除旧标记，开关状态在当前页面会话中保留。

## 文件数据格式

| 类型 | 数据结构 |
| --- | --- |
| Excel | XLSX、XLS、XLSM、XLSB 工作簿，XLTX、XLTM、XLT 模板，旧版 XLW 和 Excel 2003 XML；保留工作表、日期格式及缓存数值 |
| CSV | 首行列名；使用逗号、分号或制表符分列；支持引号包裹的单元格、换行和空值 |
| TXT | 同 CSV，可直接保存制表符分隔的设备采集表格；不是任意自然语言文档 |
| JSON | 对象数组、带首行列名的二维数组，或 `{"columns":[列名],"data":[数据行]}` |
| PMSD | PMSAMPLE v2 / 标志 3 的二进制采样文件，直接读取字段、单位、时间、数值及有效性标记 |

CSV/TXT 第一列为时间，其余列为数值。支持 UTF-8（可带 BOM）、GBK/GB18030 和带 BOM 的 UTF-16 LE/BE。测量值请使用数字，不添加单位或百分号。

默认标题规则会在载入时简化设备列名：例如 `HPODU/设备/告警1 (ID 34000) [1]` 转成 `告警1[1]`。取最后一个 `/` 后、`(` 前的文字作为 A，取 `[]` 内的内容作为 B，去掉两端空格后组成 `A[B]`；不符合完整格式的列名保留原样。规则用于全部支持的上传格式和粘贴数据的预览、序列及标签，数值不变。可在“分类配置 → 标题正则 → 编辑标题规则”修改正则、标志和替换表达式，默认替换为 `$1[$2]`。支持启用、停用、预览、恢复默认与取消；无效表达式不应用，未匹配或结果为空时保留原名。始终从原始标题处理，避免重复改名。重名列仍独立保留；新序列配置同时为勾选项和手动分配项记录原始列名及出现次序，修改规则后仍能匹配原来的数据列。

JSON 对象数组示例：

```json
[
  {"时间":"2026-11-25 18:00:40.964", "压力":1.4, "温度":-18.9},
  {"时间":"2026-11-25 18:00:41.601", "压力":1.6, "温度":null}
]
```

对象数组优先识别 `时间`、`time`、`timestamp`、`datetime`、`date` 作为时间字段，找不到时使用首个字段。合并所有记录的字段，缺失值按空单元格处理。不支持单元格内嵌套对象或数组。

二维数组示例：`[["时间","压力"],[0,1.4],[1,1.6]]`。也可写成 `{"columns":["时间","压力"],"data":[[0,1.4],[1,1.6]]}`。这两种结构使用首列作为时间。

通过上传或拖拽导入本工具导出的配置文档时，文档中的 `configs` 会加入本地配置列表，点击列表项应用；导入本地不会改变网站的 `defaults`。旧版配置对象和数组仍可导入。空配置列表不删除已有本地配置。

## Excel 工作簿与模板

点击“上传数据”或拖入文件，直接读取工作簿中的表格数据，无需先另存为 CSV。默认选择第一个可绘制的工作表；有多个工作表时，使用图表工具栏中的工作表选择框切换。各工作表仍以第一行为列名、第一列为时间，其余列为数值，保持原始行顺序，并分别沿用三类最后选择的配置。

- 支持 `.xlsx`、`.xls`、`.xlsm`、`.xlsb`、`.xltx`、`.xltm`、`.xlt`、旧版 `.xlw` 以及 Excel 2003 XML（`.xml`，不是任意 XML 文档）。
- 自动读取日期单元格格式，保留 1900/1904 日期系统；普通数值时间保持为数值，可手动切换时间格式。
- 公式使用文件中保存的计算结果，页面不重新计算公式，也不运行宏。若公式结果尚未保存，请先用 Excel 计算并保存文件。加密工作簿需要先另存为不带打开密码的副本。
- 单文件上限 50 MB，压缩格式解压后上限 200 MB；单工作表最多 250,000 行数据和 512 列。超出限制会提示，不会悄悄截取前一部分数据。
- Excel 解析库 SheetJS CE 0.20.3 来自用户提供的库文件，独立保存在 `vendor/xlsx.full.min.js`；JSZip 独立保存在 `vendor/jszip.min.js`。HTML 按顺序引用这两个本地文件，解压后可直接离线使用。许可证见 `THIRD_PARTY_NOTICES.md`。

## PMSD 采样文件

可以直接上传 `.pmsd`，无需先转换为 CSV。当前适配范围是本次提供样本中的 `PMSAMPLE` v2、标志值 3、`SMP1` 采样记录结构；其他版本或存储方式会明确提示不支持。文件头中的字段元数据和每条采样记录均进行 CRC32 校验。支持文件末尾可选的 28 字节 `END1` 结束块：核对采样记录总数和整个采样区的 CRC32，并确认结束块后无多余数据；结束块不作为曲线数据。没有结束块、但完整结束于采样边界的旧文件仍可读取。损坏、截断或未知记录结构会拒绝整次导入，保留原来的曲线。

列名按设备字段名称和单位生成，例如 `告警1[1]`、`一次侧水压[bar]`、`室外环境温度[℃]`，与现有设备标题简化规则一致。直接使用文件保存的工程值，不再根据 UINT16/INT16 等原始设备类型做倍率换算。有效性标记为无效的单元格保留为空值和曲线断点，即使对应位置仍存有数值，也不显示为有效采样。全部无效的一条记录仍保留时间和原始行位置。

时间按毫秒显示。原始文件名中的 `_年月日_时分秒_毫秒_` 与文件头开始时间一致时，用两者推断并校验时区偏移；本次样本识别为 UTC+08:00，显示与原表格一致的北京时间。建议保留原始文件名；重命名后无法推断时区时，按浏览器所在时区显示，并在页面提示。这里的时区偏移依据文件名推断，并非文件中的显式时区字段。

PMSD 同样遵循三类最后选择的配置、原始行顺序、自动上下限和区域比例。首次导入或没有匹配配置时不会自动全选。最大 50 MB、250,000 条记录、511 个数据字段加 1 个时间列。

## 从 Excel 粘贴数据

1. 在 Excel 中选中数据区域（包含首行列名），按 `Ctrl + C`。
2. 切换到页面上方的“粘贴数据”标签，点击输入框，按 `Ctrl + V`。
3. 第一列为时间，第二列起为数值；必要时选择时间格式。纯数值日期需要选择“Excel 日期数值”，Unix 时间戳需要选择秒或毫秒。
4. 点击“预览数据”确认表格，或直接点击“载入曲线”（输入框内也可按 `Ctrl + Enter`）。成功后自动切换到“曲线查看”。
5. 切换标签会保留输入内容；“清空”只清空粘贴草稿。刷新或关闭页面后草稿不会保留。载入失败会显示原因，并保留原来的曲线。

粘贴支持 Excel 的制表符分列、空单元格、带引号的多行单元格和重复列名。预览最多显示前 8 行、8 列，载入使用全部数据；上限为 50 MB 文本、250,000 行数据和 512 列。输入内容按文本处理，不执行公式或 HTML。

粘贴读取 Excel 单元格显示的文本，无法恢复未显示的小数精度或日期格式。时间显示为 `####` 时应先加宽 Excel 列；测量列请使用不带千位分隔符、单位和百分号的数值格式。需要保留精度时，请从数据源导出精度足够的 CSV、JSON 或 TXT。已保存的 JSON 配置仍按列名匹配粘贴数据。

## 时间与坐标轴

- 日期文本、`HH:mm:ss.SSS` 自动识别。纯数值默认作为数值时间；Excel 日期数值、Unix 秒/毫秒时间戳请手动选择对应格式。
- 所有时间格式都保留原始行顺序，不按时间排序，曲线按原始行顺序连接。数值/日期横轴使用真实时间坐标，时间回退时连线会向左；文本模式按原始行顺序等距排列。重复时间保留全部记录，悬浮取最近时间点，距离相同时取原始顺序中最先出现的一行。
- Excel 日期和无时区文本保留表内时间；带时区的 ISO 文本转为 UTC 显示。时分秒按当天时间解释，跨日请写完整日期。
- 空白、无效时间行跳过；空白、错误、非数值测量单元格显示断点，不补零。
- 默认按每条序列完整数据的最小值和最大值，依次选择第一个能够容纳它的坐标组：`0～10`、`−40～100`、`0～1000`、`0～10000`。因此 `20～80` 使用 `−40～100` 组。组名用于归类，自动上下限根据该组已勾选曲线的整体数据范围计算：`跨度 = 最大值 − 最小值`，`下限 = 向下取整(最小值 − 跨度 × 5%)`，`上限 = 向上取整(最大值 + 跨度 × 5%)`。例如数据为 −20～30，自动范围为 −23～33；1.4～1.6 的自动范围为 1～2。
- 常量数据的跨度为零，上下改为各扩展数值绝对值的 5%，至少扩展 1，然后同样向外取整；零值常量显示为 −1～1。无有效数值的序列不创建坐标轴。手动上下限保持输入值，不做拓宽或取整。
- 同组共用坐标轴；勾选或取消曲线会重新计算自动上下限，但不会改变其他曲线的归组。时间缩放仍按完整数据计算纵轴范围，避免纵轴随拖动跳变。超出四组预设范围的序列默认使用全高自动坐标。
- 点击“曲线坐标”，搜索或找到曲线并选择坐标组；可将任意曲线分配至任意组，或选择“自动匹配”恢复默认。未勾选的曲线也可预先分配，分配本身不会勾选曲线。点击“应用”生效，取消或 Esc 放弃修改；“全部自动匹配”重置所有曲线的分配草稿。
- 在“坐标范围”中输入数值即切换为手动范围，下限必须小于上限。同轴序列共用上下限；范围外的曲线部分会隐藏，原始数据不变。每个轴可单独“恢复自动”，也可“全部恢复自动”，都需要点击“应用”；取消或按 Esc 放弃修改。
- 手动上下限优先于自动范围，且不改变坐标组占用的区域。序列、切换时间格式和重置时间缩放会保留当前手动范围及曲线分配。载入新数据或切换工作表时分别采用最后选择的坐标轴和序列配置；未保存的临时坐标与勾选修改不作为下次加载的默认值。标题规则点击“应用”后用于当前页面的后续载入，保存标题正则配置后才能跨页面恢复。
- 最大 50 MB/文件、250,000 行/表、512 列/表。大量数据或序列会增加内存和绘制时间。

本次交付的 `configs/axes.json` 中，默认显示区域如下；修改 JSON 后以文件中的值为准。百分比从绘图区顶部向下计算，不包含工具栏和时间滑块。即使只显示一个组，也保留该组指定的位置和占比。

| 坐标组 | 显示区域 | 绘图区高度占比 |
| --- | --- | --- |
| 0～1000 | 顶部 0%～25% | 25% |
| −40～100 | 中部 25%～80% | 55% |
| 0～10 | 底部 80%～100% | 20% |
| 0～10000、自动 | 全部 0%～100% | 100% |

在左侧“分类配置 → 坐标轴 → 坐标区域”中，可分别设置五个组的起始和终止比例，包括暂未显示的组。0% 是绘图区顶部，100% 是底部；支持小数，须满足 `0 ≤ 起始 < 终止 ≤ 100`，区域高度占比为终止减去起始。各组允许重叠。可单组或全部恢复默认，点击“应用”后生效，取消或 Esc 放弃草稿；应用不改变数据、勾选、上下限和时间缩放。保存坐标轴配置后，重新加载数据和重新打开页面均按最后选择的坐标轴配置恢复区域；旧配置缺省时采用上表默认值。

## 三类独立配置

| 分类 | 保存内容 | 云端文件与导出文件名 |
| --- | --- | --- |
| 坐标轴 | 时间格式、纵轴上下限、各组区域起止比例 | `configs/axes.json` |
| 标题正则 | 启用状态、匹配表达式、标志、替换表达式 | `configs/regex.json` |
| 序列 | 已序列及颜色、全部手动坐标轴分配（包括未序列） | `configs/selection.json` |

每类单独显示本地与云端列表、当前选择和已修改状态。保存只更新本地当前分类，应用不会覆盖其他分类；同类同名更新，跨类同名独立。本地与云端的同名项也互相独立：选中云端项后点击保存，会新增或更新本地副本。坐标轴区域和标题正则可在载入数据前编辑、保存；序列需先载入数据，允许保存空选择。

“导出”读取本地数据库，将当前类型的全部配置放入文档的 `configs` 数组，同时保留当前已加载的 `defaults`，例如两套坐标轴配置共同存入 `axes.json`。没有此类本地配置时 `configs` 为 `[]`，默认值仍保留。手动将下载文件替换到网站 `configs` 目录，即更新该类云端配置；页面不会写回磁盘。导出不自动合并云端旧项，需要保留时先导入本地或合并 `configs` 数组。同类配置名称须唯一，单文件最多 1,000 项、10 MB。交付文件已填入当前默认值，配置列表为空，不包含示例曲线数据。

云端目录只读取其直接包含的三个 JSON，不扫描子目录；每个文件只允许对应类型。文件使用 `schema: "curve-viewer-bundle"`、`version: 1`、`type`、`defaults`、`configs` 五个字段。三个文件和有效默认值均为必需项；缺失或格式错误会提示，不使用隐藏的硬编码默认值。首次读取失败时暂不能处理新数据，可修复文件后刷新云端重试；后续刷新失败会保留之前已验证的默认值、配置列表与曲线。成功刷新后，“恢复默认”和后续导出使用新默认值，已有曲线不会被自动覆盖。

默认值字段对应关系：

| 文件 | `defaults` 中的内容 |
| --- | --- |
| `axes.json` | `timeMode`、`axisLimits`、`axisRegions`、`axisGroups`、`autoBounds` |
| `regex.json` | `headerRule`，包含启用状态、表达式、标志、替换内容 |
| `selection.json` | `selectedSeries`、`seriesAxes`、`palette`、`fallbackColor` |

未选择个人勾选配置时按 `defaults.selectedSeries` 匹配；当前交付值为空，继续保持首次加载不勾选。详细字段说明见 `configs/README.md`。

本地配置的新增、更新和删除以 IndexedDB 事务完成为准；失败会提示，不显示保存成功。不可用时仍可载入数据和查看云端配置，本地保存、导入与导出不可用。删除本地项不会删除云端同名项，也不会删除磁盘 JSON；删除已选中的本地项会清除该类的默认选择，当前图形保留。

标题正则使用 JavaScript 正则语法，填写表达式本体，不加两侧斜杠；标志支持 g、i、m、s、u，替换文本支持 $1、$2、$& 等。预览仅处理文本，不执行 HTML。每次修改都从原始列名重新处理，当前数据行、勾选、颜色、曲线分组和纵轴设置保留。时间列名称也按同一规则处理，时间值不变。

导入旧版 v1 合并配置时，自动拆为同名的坐标轴与序列两份，不生成合并配置。浏览器旧版 localStorage 中的配置及其最后选择会一次性迁移到 IndexedDB；迁移后以数据库为准，删除不会被旧缓存重新导入。原有 JSON 文件不改写。旧版没有可编辑标题规则，继续使用默认规则或已选的标题正则配置。

配置条目仍使用 curve-viewer v2，type 分别为 axes、regex、selection。以下示例是文档 `configs` 数组中的一个条目；旧版单个 JSON 对象和数组仍可导入本地，新的云端文件须同时包含 `defaults` 和 `configs`：

坐标轴：

```json
{
  "schema": "curve-viewer",
  "version": 2,
  "type": "axes",
  "name": "温度轴",
  "timeMode": "auto",
  "axisLimits": {
    "thermal": {
      "min": -20,
      "max": 60
    }
  },
  "axisRegions": {
    "thermal": {
      "start": 25,
      "end": 80
    }
  }
}
```

标题正则：

```json
{
  "schema": "curve-viewer",
  "version": 2,
  "type": "regex",
  "name": "设备标题",
  "headerRule": {
    "enabled": true,
    "pattern": "^.*\\/\\s*([^/()]*?\\S)\\s*\\([^()]*\\)\\s*\\[\\s*([^\\[\\]]*?\\S)\\s*\\]\\s*$",
    "flags": "",
    "replacement": "$1[$2]"
  }
}
```

序列：

```json
{
  "schema": "curve-viewer",
  "version": 2,
  "type": "selection",
  "name": "温度曲线",
  "selectedSeries": [
    {
      "name": "温度",
      "occurrence": 1,
      "sourceName": "温度",
      "sourceOccurrence": 1,
      "color": "#5465e8"
    }
  ],
  "seriesAxes": [
    {
      "name": "温度",
      "occurrence": 1,
      "sourceName": "温度",
      "sourceOccurrence": 1,
      "axisId": "thermal"
    },
    {
      "name": "压力",
      "occurrence": 1,
      "sourceName": "压力",
      "sourceOccurrence": 1,
      "axisId": "auto"
    }
  ]
}
```

坐标组键为 small、thermal、medium、large、auto，依次对应 0～10、−40～100、0～1000、0～10000 和自动。axisLimits 的 min/max 为手动上下限，未指定使用自动范围；axisRegions 的 start/end 是从顶部计的 0～100 百分数；seriesAxes 可保存未勾选曲线的分组。

`selectedSeries` 只记录已序列；`seriesAxes` 只记录手动分配坐标轴的序列，两者都属于序列配置。未勾选且未分配的序列不会写入任何列表。上例恢复时只勾选温度，压力保持未勾选，但再次勾选压力时仍使用指定坐标组。手动指定 `auto`（全高度自动组）也会保存；选择“自动匹配”则移除该条手动分配。搜索筛选不会遗漏其他未显示序列的手动分配。切换坐标轴配置不会修改序列归属；切换序列配置会同时恢复勾选和分配。

2.2.2 会一次性迁移本地 IndexedDB 中旧坐标轴配置的分配；同名旧序列配置存在时合入该序列配置，最后选择的两类本地配置名称不同时也保留原组合的分配。没有可合并的旧序列配置，或同名新序列配置已显式保存分配时，额外生成“原名（旧坐标分配）”序列配置以保留旧内容，默认不勾选曲线。导入旧文件、读取旧云端文件时同样兼容；同名新配置的分配不会被迁移覆盖。重新导出后，axes.json 不再含 seriesAxes，selection.json 保存分配；云端原文件由用户手动更新。只导入旧 axes.json 时，其分配会生成带上述后缀的序列配置。

勾选与分组优先按原始列名及其出现次序匹配，再兼容显示列名和旧默认简称；未找到的序列不勾选。配置不包含数据，清空数据保留三个分类及最后选择。删除一个分类的配置不会移除其他分类的同名项。

## 维护

- `src/`：页面模板、样式、数据处理与交互代码。
- `src/config-store.js`：IndexedDB 事务、旧配置迁移、按类型导出和只读云端文件解析。
- `configs/`：三个按类型合并的云端 JSON 及目录说明。
- `vendor/`：由 HTML 相对路径引用的独立第三方 JS 与许可证，许可证见 `THIRD_PARTY_NOTICES.md`。
- 修改源码后运行 `node build.cjs` 更新 `index.html`。
- Node.js 18 或更高版本可运行维护命令，日常打开 HTML 不需要 Node.js。
- 维护测试先运行 `npm ci` 安装开发依赖，再运行 `npm test`（或 `npm run test:core`），检查 Excel/CSV/JSON/TXT/PMSD 导入、编码、粘贴、时间、量程、配置及交互逻辑。IndexedDB 测试使用 `fake-indexeddb`，交互测试使用 DOM/图表替身，不替代真实浏览器验收。PMSD 测试使用合成数据，交付包不包含原始设备采样文件。
- Excel 上传检查已纳入 `npm test`，也可单独运行 `npm run test:excel`。旧版手写 OOXML 适配器测试仅作历史对照，运行 `npm ci` 后可使用 `npm run test:legacy-excel`；当前上传入口使用本地 `vendor/` 中的 SheetJS。
- `node preview.cjs` 仅供开发时本地预览，静态网站部署和使用不依赖此脚本。
- 运行 `npm run package` 重建页面并生成完整项目包 `curve-viewer.zip` 和静态部署包 `curve-viewer-static.zip`，同时检查脚本语法、依赖路径、云端 JSON 类型、归档 CRC 和逐文件内容。压缩包不包含 `node_modules` 或临时文件。
- 本次交付检查范围见 `RELEASE_NOTES.md`，更新文件清单见 `UPDATED_FILES.md`。

图表使用原生 Canvas，上传文件在本地解码并解析；PMSD 解析也无需外部 CDN 或远程 API。
